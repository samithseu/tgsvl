# tgsvl (Telegram Serverless)

Simple Starter Template for Telegram Serverless with Mini App. It's really interesting because it allows us to:

- Manage bot **logic**, which is like a server-side logic, in [tgcloud/](./tgcloud/) folder
- Have a **static-site** hosting by specifying `build` folder in [tgcloud.jsonc](./tgcloud.jsonc)
- Much more...

## References

- Read [Telegram Serverless Docs](https://core.telegram.org/bots/serverless#mini-app-front-end) to learn more.
